Featured Project

Ecommerce Platform

A full-featured ecommerce platform built with Django, combining a server-rendered MVT application with a REST API. The project covers product discovery, shopping cart, checkout, orders, payments, reviews, authentication, and administration.

The main focus of the project was implementing realistic business rules and handling backend concerns such as stock validation, cart consistency, authentication, caching, background processing, and concurrent updates.

Key Features

  • Authentication & Authorization: JWT authentication and role-based access control.
  • Product Management: Products, categories, images, publishing status, discounts, stock, and product relationships.
  • Product Discovery: Search, filtering, sorting, pagination, category filtering, and price filtering.
  • Pricing: Discount handling and final-price calculation at the database level.
  • Guest Cart: Redis/cache-based cart for unauthenticated users.
  • Authenticated Cart: Database-backed cart for authenticated users.
  • Cart Merging: Guest cart items are merged into the user's database cart after authentication.
  • Stock Validation: Cart and order operations validate available stock.
  • Concurrency Handling: Cache locking is used to prevent conflicting cart updates.
  • Orders & Checkout: Address management, order creation, coupon usage, and checkout workflow.
  • Payments: Payment workflow and gateway integration.
  • Reviews: Product reviews, ratings, approval workflow, and moderation.
  • Admin Dashboard: Management functionality for products, orders, reviews, tickets, and other resources.
  • Testing: Automated API and business-logic tests with pytest.
  • API Documentation: OpenAPI / Swagger documentation.

Technical Highlights

  • PostgreSQL as the primary relational database.
  • Redis for caching and cart management.
  • Cache locking for concurrent cart updates.
  • Django ORM annotations for database-level final-price calculations.
  • Celery for background processing.
  • Docker and Docker Compose for development and service orchestration.
