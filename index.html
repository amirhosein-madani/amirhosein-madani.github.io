Selected Work

Projects

A selection of backend projects I've worked on while learning and building practical systems.

01

E-commerce Platform

Ecommerce

GitHub ↗

A full-featured Django ecommerce application built around practical backend requirements. The project includes authentication, product management, categories, cart, orders, payments, reviews and a dashboard for managing the application.

The backend uses PostgreSQL for persistent data, Redis for caching and cart-related operations, and Celery for background processing. The application also includes stock validation, filtering, pagination, API documentation and automated tests with Pytest.

One of the more challenging parts of the project was handling cart concurrency. A cache-based locking mechanism is used to prevent conflicting cart updates when multiple requests try to modify the same cart at the same time.

Python Django DRF PostgreSQL Redis Celery Docker Pytest
02

Performance / Research

API Latency Lab

GitHub ↗

A collaborative backend project focused on studying API performance and understanding how different implementation approaches affect latency and system behavior.

The project explores database performance, Redis caching, synchronous and asynchronous processing, background tasks and load testing with Locust. Different approaches are tested and compared to better understand their performance characteristics.

Working on this project also gave me experience with collaborative development and a more research-oriented approach to backend engineering, including experimentation, benchmarking and analyzing results.

Django FastAPI PostgreSQL Redis Celery Locust Docker
03

Team Project

Library Management

A collaborative library management backend designed to handle books, authors, categories, publishers, loans, reservations and users.

The project was developed as a team, providing practical experience with collaborative backend development, working with a shared codebase and integrating different parts of the application.

The backend is built with Django and Django REST Framework and uses PostgreSQL for data storage, Redis for caching and Docker for containerized development.

Python Django DRF PostgreSQL Redis Docker
